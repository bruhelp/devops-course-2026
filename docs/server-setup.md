# Конфигурация виртуальной машины devops-vm
1. ## Параметры машины
* **Объём памяти:** 2 ГБ (2048 МБ)
* **Количество ядер:** 2 CPU
* **Объём диска:** 20 ГБ (динамический виртуальный диск)

## 2. Сетевые интерфейсы
* **Адаптер 1 (NAT):** используется для выхода виртуальной машины в интернет и синхронизации пакетов.
* **Адаптер 2 (Виртуальный адаптер хоста / Host-Only):** 
  * Полученный адрес: `192.168.56.10` (статический или по DHCP)
  * Назначение: обеспечение стабильного доступа с хостовой машины (пользовательского ПК) к сервисам виртуальной машины (веб-сайт, SSH, Nginx).

## 3. Правило проброса портов
* **Порт хостовой системы:** `2222` $\rightarrow$ **Порт гостевой системы:** `22` (для подключения по SSH с хоста)
* **Порт хостовой системы:** `443` $\rightarrow$ **Порт гостевой системы:** `443` (для доступа по HTTPS к Nginx)

## 4. Учётные записи
* **Имя:** `vboxuser` 
  * Принадлежность к группам: `vboxuser`, `sudo`, `adm`
  * Способ аутентификации: парольный вход
* **Имя:** `devops` 
  * Принадлежность к группам: `devops`, `sudo`, `docker`
  * Способ аутентификации: SSH-ключи (парольная аутентификация заблокирована)

## 5. Служба SSH
* **Порт:** `2222`[cite: 8]
* **Изменённые директивы и их значения:**
  * `PermitRootLogin no` (запрещен вход под суперпользователем)[cite: 8]
  * `PasswordAuthentication no` (отключена аутентификация по паролю)[cite: 8]
  * `Port 2222` (изменен стандартный порт)[cite: 8]
  * `MaxAuthTries 3` (ограничено число попыток ввода данных)[cite: 8]
* **Расположение файла конфигурации:** `/etc/ssh/sshd_config`

## 6. Правила межсетевого экрана
* **Политики по умолчанию:**
  * Входящий трафик (`Incoming`): `deny` (запрещено всё, что явно не разрешено)[cite: 8]
  * Исходящий трафик (`Outgoing`): `allow` (разрешено всё)
* **Перечень правил:**
  * Разрешен входящий трафик на порт SSH (`2222/tcp`)
  * Разрешен входящий трафик для веб-сервера (`Nginx Full` / порты `80` и `443`)

## 7. Снимки состояния
* **Наименование:** `Clean Install` — момент создания: сразу после первичной установки ОС Ubuntu Server и базовой настройки сети.
* **Наименование:** `Hardened & Dockerized` — момент создания: после завершения настройки безопасности (SSH, UFW, Nginx с SSL) и развертывания контейнеризованного приложения (Flask + PostgreSQL через Docker Compose).

## 9. Контейнеризация
* **Способ установки Docker Engine и его версия:** Установка из официального репозитория Docker с помощью apt-get (Docker version 24+ / актуальная стабильная версия).
* **Участники группы `docker`:** пользователь `devops`.
* **Расположение проекта на сервере:** `/home/devops/app/` (или `~/app/`)[cite: 9].
* **Расположение файла `.env` и его права:** `/home/devops/app/.env`, права доступа жестко ограничены — `600` (`-rw-------`), владение пользователем `devops`.
* **Публикуемые порты и адреса:** Приложение Flask привязано исключительно к локальному интерфейсу обратной петли хоста контейнера — `127.0.0.1:5000:5000` (порт СУБД `5432` наружу не публикуется и доступен только внутри изолированной сети).
* **Именованные тома:** `app_db_data` (используется для персистентного хранения данных СУБД PostgreSQL в `/var/lib/postgresql/data`).
* **Конфигурация обратного прокси-сервера:** В файл конфигурации Nginx (`/etc/nginx/sites-available/devops-site`) добавлен блок `location /app/`, выполняющий проксирование запросов на бэкенд:
  ```nginx
  location /app/ {
      proxy_pass [http://127.0.0.1:5000/](http://127.0.0.1:5000/);
      proxy_set_header Host              $host;
      proxy_set_header X-Real-IP         $remote_addr;
      proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
      proxy_set_header X-Forwarded-Proto $scheme;
  }
