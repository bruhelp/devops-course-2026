# Ответы на вопросы.

## 1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?

В Git ветка — ссылка на коммит в истории. Все операции внутри неё локальные, которые не копируют файлы и истории. Ветка — указатель, который можно двигать. Поэтому ветвление почти бесплатное.

В SVN ветка является отдельным каталогом в дереве репозиториев. В отличие от Git ветка — это не указатель, а полноценная директория.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нельзя, потому что SVN — центализированная система. В ней коммиты являются операцией над центральным репозиторием, который не доступен без доступа к серверу (интернету). Возможны только локальные изменения.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

SVN до сих пор используется в legasy-проектах, особенно в госсекторе и банках. SVN полезен для поддержания старых систем. Git сильнее в распределённой работе, ветвлениях и слияниях.
